Инструкция:
1. Как запускать:
   1 вариант. Скачать все файлы на компьютер с мос хаб, заходим в директорию Front, и нажимаем на index.html.
   2 вариант. Чтобы посмотреть сайт на телефоне, нужно перейти по ссылке: 
2. Где что лежит:
   Директория Front:
   1) файлы html лежат отдельно в данной директории
   2) стили лежат в папке style
   3) скрипты лежат в папке script
   4) фотографии и иконки, использованные на сайте, лежат в папке Фото
   Директория Documentation:
   1) в ней находятся все файлы документации
   Директория Design:
   1) в данной директории находится файл с ссылкой на проект в Figma
   Директория Analysis:
   1) в ней находится файл с описанием целевой аудитории
3. Перемещение по сайту:
   1) сначала заходим на главную index.html
   2) на каждой странице есть боковая панель навигации и шапка, по ним происходит перемещение по страницам
   3) с каждой страницы можно перейти на любую другую
   4) нажимая на карточки и слайды в слайдере, вы переходите на описание отдельной новости
   5) нажимая на сердечко в каждой карточке, новость (карточка) добавляется на страницу избранное
   6) слайды в слайдере можно менять по стрелкам вперед-назад, кроме того они меняются через каждые 6 секунд
   7) нажимая на иконку фильтра на странице "все новости", вылезает модальное окно, где вы можете настроить новости под свои интересы, кроме того есть быстрые фильтры только по тегам
   8) на странице "избранное" можно удалить именно выбранную новость, нажав на квадратик рядом, а также удалить сразу все новости одной кнопкой "очистить"
   9) по поиску на странице "все новости" можно найти определенную новость по названию
   10) в настройках можно поменять тему с помощью радио и включить/выключить уведомления с помощью переключателя
   11) в настройках есть форма с полями "ФИО" и "Группа" с валидацией и кнопкой "Сохранить изменения", эта страничка объединяет в себе настройки и профиль
   12) на странице "Уведомления" вы можете посмотреть все уведомления за последнее время и, нажав на каждое, посмотреть к какой новости оно относится
   13) нажав на кнопку "Выйти" в боковой панели навигации, вылезает модальное окно с сообщением и кнопками "Выйти" и "Отмена", по первой кнопке обновляется страница и удаляются данные в профиле, по второй кнопке модальное окно закрывается
